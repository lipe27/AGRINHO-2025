O site tem como objetivo principal apresentar e aprofundar temas relevantes que envolvem a conexão entre o meio rural (campo) e o meio urbano (cidade). Através de uma abordagem educativa, o site destaca a importância dessa relação para o desenvolvimento sustentável, a valorização da cultura local, a preservação ambiental e o fortalecimento da economia regional.

Cada página do site é dedicada a um tema específico, como:

Sustentabilidade no Campo e na Cidade: Informações sobre práticas sustentáveis, como agricultura responsável, manejo dos recursos naturais, e consumo consciente.

Educação Rural e Urbana: A importância da educação integrada para promover o desenvolvimento social e a redução das desigualdades.

Desenvolvimento Regional: Como a cooperação entre áreas rurais e urbanas pode impulsionar a economia local, gerar emprego e melhorar a qualidade de vida.

Cultura e Tradições: Valorização das tradições rurais e urbanas, mostrando como elas influenciam a identidade das comunidades.

Programa Agrinho 2025: Apresentação dos objetivos e ações do programa, que visa incentivar a educação e sustentabilidade na região.

Explicação das Seções do Código do Site
1. Estrutura HTML

<html>, <head> e <body>:
Base da página, onde o <head> contém metadados, links para estilos (CSS), e o título da página; o <body> contém o conteúdo visível ao usuário.

<header>:
A seção do cabeçalho, geralmente com o logo do site e o menu de navegação para acessar as diferentes páginas.

<nav>:
O menu de navegação, que permite o usuário navegar entre as páginas temáticas do site.

<main>:
A parte principal do conteúdo da página. Aqui ficam os textos, imagens e qualquer outro conteúdo informativo.

<section>:
Usado para dividir o conteúdo em blocos temáticos, como os temas “Sustentabilidade”, “Educação”, etc.

<footer>:
Rodapé do site, contendo informações como direitos autorais, contatos ou links adicionais.
  
2. Estilos CSS

Define a aparência do site: cores, fontes, espaçamentos, tamanhos e alinhamentos.

Garante que o site tenha uma identidade visual coerente, com cores e fontes que facilitem a leitura e deixem o site agradável.

Pode incluir estilos para tornar o site responsivo (adaptável a telas de celulares, tablets e desktops).

3. Framework Bootstrap

Biblioteca que facilita a criação de sites responsivos e modernos.

Utiliza classes prontas para organizar o layout em grades (grid system), botões, menus, formulários e outros componentes.

Garante que o site funcione bem em diferentes dispositivos sem precisar programar tudo do zero.

Explicação bloco a bloco

1- 
<!DOCTYPE html> e <html lang="pt-BR">
Define o tipo do documento como HTML5 e o idioma da página como português do Brasil.

2- 
<head>
Contém informações importantes para o navegador: codificação, título da página, links para estilos CSS (Bootstrap e personalizado).

3- 
<body>
Contém todo o conteúdo visível do site.

4- 
<header>
Cabeçalho fixo com fundo verde escuro, texto branco, que contém o título do site e o menu de navegação para as páginas principais.

5- <nav> e <ul class="nav">
Menu de navegação com links para outras páginas, usando classes do Bootstrap para formatação horizontal.

6- <main class="container my-4">
Principal área de conteúdo do site, centralizada e com margens verticais para espaçamento.

7- <section> (introdução)
Bloco com título, texto e imagem, apresentando o site e seus objetivos.

8- Seções temáticas de Sustentabilidade, Educação e Desenvolvimento
Cada uma com título, texto explicativo e imagem ilustrativa, separadas por margens para clareza visual.

9- <footer>
Rodapé escuro com texto branco centralizado, contendo direitos autorais.

10- Scripts do Bootstrap
Inclusão dos arquivos JavaScript do Bootstrap para garantir funcionamento dos componentes interativos, se houver.
